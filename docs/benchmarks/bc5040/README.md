Two lower bounds, both sound, one much tighter.

**Entropy floor 3.230** -- log2(5040) / log2(outcomes), assuming every guess splits the space perfectly evenly. True but weak: no single code splits the candidates into equal parts, let alone repeatedly.

**Counting floor 4.488** -- a strategy is a decision tree whose nodes have at most one winning edge, so at most `(outcomes - 1) ** (j - 1)` secrets can be solved on guess `j`. Packing the space as shallowly as those caps allow bounds the mean. It uses nothing about any position, which is what makes it sound.
